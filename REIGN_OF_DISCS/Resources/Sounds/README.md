# 効果音・BGM の置き場所

このフォルダに次の名前のファイルを置くと、ゲームが自動で読み込んで鳴らします。
ファイルがなくてもゲームは無音のまま問題なく動きます（素材は同梱していません）。

| ファイル名（拡張子を除く） | 鳴る場面 |
|----------------------------|----------|
| `se_place` | 石を置いたとき（戦術的配置を含む） |
| `se_flip` | 石が反転したとき（強制反転を含む） |
| `se_resource` | 資源を獲得したとき（資源採掘を含む） |
| `se_button` | ボタンを押したとき、建設・能力を使ったとき |
| `se_error` | 置けない場所・資源不足など、操作が拒否されたとき |
| `bgm_title` | タイトル・モード選択・設定・結果画面（ループ） |
| `bgm_game` | ゲーム画面（ループ） |

- 拡張子は `.wav` → `.ogg` → `.mp3` の順に探します（同じ名前で複数ある場合は先に見つかったもの）。
- ビルドすると、このフォルダの中身が実行ファイルの隣の `Resources\Sounds\` にコピーされます。ビルド後に素材を追加した場合は、もう一度ビルドするか、`x64\<構成>\Resources\Sounds\` にも直接置いてください。
- 音量はタイトル画面の「設定」で変えられます（ゲームを終了すると初期値に戻ります）。
