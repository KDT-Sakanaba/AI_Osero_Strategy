- 作成日: 2026-11-10
- 原典: 1章、2章、5.1、7.3、8章（8.1〜8.5）、10章、11章、12章、15章、16章 Phase 1〜3、17章 T001〜T008・T015

## 目的
Visual Studio・C++・DXライブラリでゲームの土台（ウィンドウ・メインループ・シーン管理・入力）を作り、AI なしのローカル2人対戦で通常オセロを最初から最後まで遊べるようにする。後の F002（ストラテジー）・F003（AI）が載る盤面ロジックとシーン構成を、ここで確定させる。

## ユーザー視点の動作
1. 起動すると 1280×720 のウィンドウにタイトル画面が出る。項目は「ゲーム開始」「設定」「終了」。
   - 「設定」は F004 で中身を作るまで選べない（灰色表示）。
   - 原典 8.1 の「モード選択」は「ゲーム開始」と同じ遷移先のため、独立した項目にしない（確認履歴 参照）。
2. 「ゲーム開始」でモード選択画面へ進む。2段階で選ぶ。
   - ルール: 「通常オセロ」「ストラテジー」
   - 対戦相手: 「ローカル2人対戦」「AI（EASY / NORMAL / HARD）」
   - F001 の時点では「通常オセロ × ローカル2人対戦」だけを選べる。他は灰色で「未実装」と表示する。
   - 「戻る」でタイトルへ戻る。
3. ゲーム画面は、中央に 8×8 の盤面、左にプレイヤー（黒・先手）の情報、右に敵（白・後手）の情報、下部にターン・手番・パスボタン・メッセージログを表示する。
   - ローカル2人対戦の表示名は「プレイヤー1（黒）」「プレイヤー2（白）」とする。
   - 通常オセロでは資源・拠点・能力・建設の表示を出さない。
4. 手番側の合法手のマスに目印（小さな点）を出す。マウスを乗せたマスは枠線で強調し、座標を表示する。
5. 合法手のマスを左クリックすると石を置き、挟んだ敵石をすべて反転し、手番が相手に移る。メッセージ「敵の石をN個反転しました」を出す。
6. 合法手でないマスのクリックでは何も変化しない（メッセージ「そこには置けません」を出す）。右クリックは選択の解除。
7. 手番側に合法手がないときは自動でパスし、「<名前>は置ける場所がないためパスしました」を表示する。両者が続けてパスするか、64マスが埋まるとゲームが終わる。
8. 結果画面に勝者（または引き分け）と両者の石数を出す。「もう一度」で同じ設定のまま再戦、「タイトルへ」でタイトルに戻る。
9. ESC でポーズメニュー（「続ける」「タイトルへ戻る」）を開く。メニュー中は盤面を操作できない。
10. 画面を切り替えた直後のクリック・キー入力は、新しい画面の操作として扱わない。

## 要件
- R-01 開発環境: Visual Studio の C++ デスクトップ プロジェクト（`.sln`）で DXライブラリを使う。ウィンドウモード、1280×720、ソースは UTF-8。
- R-02 構成: 原典 10.2 のフォルダ構成とクラス責務（10.3）に従う。F001 で作るのは Game、SceneManager、Title/Select/Game/ResultScene、Board、Cell、MoveValidator、TurnManager、VictoryManager、Player、BoardRenderer、GameUI、InputManager、Constants.h、Types.h（設計で補助クラス GameSession・FlipRule・FontSet を追加。plan.md 参照）。
- R-03 盤面: 8×8、左上 (0,0)〜右下 (7,7)。初期配置は (3,3)=白、(4,4)=白、(4,3)=黒、(3,4)=黒。プレイヤー（黒）が先手。
- R-04 合法手: 原典 2.3・12.2・12.4 に従う。8方向の探索順は原典 12.1 の配列順。
- R-05 反転: 合法手判定で得た反転対象リストだけを使って反転する（原典 12.3）。反転対象が0個なら何も変更しない。
- R-06 パス: 合法手がなければ自動パス。パスした側のターン数を進め、連続パス数を記録する。両者が連続でパスしたら終了する。合法手がある間は手動でパスできない（パスボタンは合法手がないときだけ有効。通常オセロでは自動パスするため実質使われない）。
- R-07 終了・勝敗: 64マス埋まる／両者連続パスで終了。石数が多い側の勝ち、同数は引き分け（原典 2.5）。
- R-08 ターン表示: 「ターン N」は通算の手番数（先手の1手目を1とし、パスも1手番と数える）。
- R-09 入力: 原典 8.4 のマウス・キー操作。入力は InputManager に集約し、押した瞬間（トリガー）を判定する。シーン切り替え後の最初のフレームは入力を捨てる。
- R-10 メッセージ: 画面下部のメッセージログに最新3件を出し、最新の1件は一定時間（3秒）強調表示する。
- R-11 安全性: 盤面外アクセス、配置不可マスへの配置、両者パス、シーン切り替え時の入力残留でクラッシュしない（原典 15章）。DXライブラリのリソースはシーン終了時・ゲーム終了時に解放する。
- R-12 ロジックテスト: 盤面ロジック（Board・MoveValidator・TurnManager・VictoryManager）を、DXライブラリに依存しないテスト用コンソール実行ファイルで自動テストする（外部テストフレームワークは使わない）。
- R-13 描画: 原典 8.3 の配色。石は DXライブラリの図形描画（円）で描き、画像素材がなくても遊べるようにする。日本語テキストを表示できるフォントを使う。

## 受け入れ条件
- AC-01: Visual Studio で Debug・Release (x64) の両方がビルドでき、起動するとタイトルが「REIGN OF DISCS」の 1280×720 のウィンドウが表示され、×ボタン・「終了」で正常に終了する。
- AC-02: 初期盤面が R-03 のとおり（T001）。
- AC-03: 合法手の目印は合法手のマスだけに表示され、合法手以外のマスをクリックしても盤面・手番が変わらない（T002・T003）。
- AC-04: 1方向・複数方向の反転が正しい（T004・T005）。端・角に到達する方向、空白で途切れる方向、自石が隣接する方向が不成立になる。
- AC-05: 合法手がない側は自動でパスし、メッセージが出る。両者連続パスでゲームが終わる（T006・T007）。
- AC-06: 64マスが埋まったときと、両者パスで終わったときの勝敗・引き分けの判定が正しい（T008）。
- AC-07: タイトル → モード選択 → ゲーム → 結果 →（もう一度／タイトルへ）の遷移が正常に動き、ESC メニューから「タイトルへ戻る」ができる。遷移直後のクリックが次の画面で誤って処理されない（T015）。
- AC-08: ローカル2人対戦で通常オセロを最初から最後まで遊べる（ユーザーの手動確認）。
- AC-09: ロジックテスト用の実行ファイルで T001〜T008 相当のテストがすべて成功する。
- AC-10: 日本語のメッセージが文字化けせずに表示される。

## 前提・制約
- 環境（2026-11-10 時点の調査）: Visual Studio Community 2019・2022・2026 がインストール済みで、いずれも C++ ツールあり。DXライブラリは見つからなかった（`C:\` を深さ6まで検索）。
- DXライブラリ以外の外部依存を増やさない。
- Visual Studio 2022（ツールセット v143、x64）を使う。
- DXライブラリはプロジェクト内の `ThirdParty/DxLib/` に同梱し、相対パスで参照する。入手は Claude が実装開始時（F001 の最初のタスク）に公式サイト（https://dxlib.xsrv.jp/）の Visual C++ 用パッケージから行う。
