[Heading1] 1. 企画概要
[Heading2] 1.1 ゲームコンセプト
本作は、オセロの基本ルールである「石を挟んで反転させる」というシステムを基礎とし、領土の獲得、資源の管理、拠点の建設、特殊能力の使用など、ストラテジーゲームの要素を融合させたターン制ボードゲームである。
プレイヤーは自勢力の石を盤面に配置し、敵勢力の石を反転させながら領土を拡大する。石の数だけでなく、資源マスの確保、施設の建設、能力の発動、敵の行動予測などが勝敗に影響する。
[Heading2] 1.2 ゲームの基本的な流れ
[ListNumber] ゲーム開始時にプレイヤーと敵勢力を決定する。
[ListNumber] 初期配置された石を確認する。
[ListNumber] 自分のターンで配置可能なマスを確認する。
[ListNumber] 石を配置して敵の石を挟み、反転させる。
[ListNumber] 領土の占領状態に応じて資源を獲得する。
[ListNumber] 資源を消費して施設建設や特殊能力を使用する。
[ListNumber] 敵勢力も同様に行動する。
[ListNumber] 盤面が埋まる、または両勢力が行動不能になった場合に勝敗を判定する。
[Heading2] 1.3 ゲームデザインの重要方針
[ListBullet] オセロの基本的なルールをゲームの中心に据える。
[ListBullet] ストラテジー要素が強くなりすぎて、オセロとして成立しなくなることを防ぐ。
[ListBullet] 特殊能力は強力だが、使用回数や資源コストによって制限する。
[ListBullet] 運要素を極力減らし、プレイヤーの判断によって勝敗が左右されるようにする。
[ListBullet] 初心者でも基本操作を理解できるUIにする。
[ListBullet] 慣れたプレイヤーには複数の戦略を選べる奥深さを提供する。
[Heading1] 2. ゲームルール仕様
[Heading2] 2.1 盤面仕様
基本盤面は8×8の64マスとする。座標の原点は左上で、左上を(0,0)、右下を(7,7)とする。
| 項目 | 内容 |
| X座標 | 0～7 |
| Y座標 | 0～7 |
| 石の所有者 | 空白・プレイヤー・敵 |
| マスの種類 | 通常・資源・拠点・特殊 |
| 建設施設 | なし・施設ID |
| 地形効果 | 地形ID |
| 占領状態 | 未占領・プレイヤー・敵 |
[Heading2] 2.2 初期配置
通常のオセロと同じく、中央4マスにプレイヤーの石2個、敵の石2個を互い違いに配置する。初期配置はゲーム開始時に固定する。
[Heading2] 2.3 石の配置ルール
プレイヤーは自分のターンに1マスへ石を配置できる。配置可能条件は、対象マスが空白であり、8方向のいずれかで隣接する敵石の連続列の先に自分の石が存在することである。
[ListBullet] 上
[ListBullet] 下
[ListBullet] 左
[ListBullet] 右
[ListBullet] 左上
[ListBullet] 右上
[ListBullet] 左下
[ListBullet] 右下
1回の配置で複数方向の敵石を反転できる。
[Heading2] 2.4 パスルール
[ListBullet] 配置可能なマスが存在しない場合、自動的にパスする。
[ListBullet] パスした場合は手番を相手へ移し、パスしたプレイヤーのターン数を進める。
[ListBullet] 連続パス数を記録する。
[ListBullet] 両勢力が連続してパスした場合、ゲームを終了する。
[Heading2] 2.5 勝敗判定
以下のいずれかでゲームを終了する。
[ListBullet] 盤面の64マスがすべて埋まった。
[ListBullet] 両勢力が連続してパスした。
[ListBullet] シナリオ等で設定された特殊勝利条件が成立した。
| 条件 | 結果 |
| プレイヤーの石が多い | プレイヤー勝利 |
| 敵の石が多い | 敵の勝利 |
| 石数が同数 | 引き分け |
基本モードでは最終的な石の数を比較する。ストラテジーモードでは、将来的に拠点制圧などの特殊勝利条件を設定できる設計とする。
[Heading1] 3. ストラテジーシステム
[Heading2] 3.1 資源システム
ゲーム内ではマナ、鉱石、影響力の3種類の資源を使用する。資源は主に盤面上の資源マスから獲得する。
| 資源 | 用途 |
| マナ | 特殊能力の使用 |
| 鉱石 | 施設の建設 |
| 影響力 | 強力な戦術・特殊ユニット等の使用 |
[Heading2] 3.2 資源の初期値
| 資源 | 初期値 | 最大保有量 |
| マナ | 3 | 15 |
| 鉱石 | 2 | 15 |
| 影響力 | 0 | 10 |
最大保有量を超えた分の資源は獲得できない。
[Heading2] 3.3 資源獲得
資源マスを自勢力の石で占領している場合、ターン開始時に資源を獲得する。同じマスからの資源獲得は1ターンにつき1回までとする。
| マス | 獲得資源 |
| マナ鉱脈 | マナ +2 |
| 鉱石鉱脈 | 鉱石 +2 |
| 祭壇 | マナ +1、影響力 +1 |
| 中立拠点 | 影響力 +1 |
[Heading2] 3.4 施設建設
施設は自勢力が占領しているマスに建設できる。建設は自分のターンに実行し、基本ルールでは1ターンにつき1施設まで建設可能とする。
| 施設 | 建設コスト | 効果 |
| 採掘所 | 鉱石3 | ターン開始時に鉱石+1 |
| 魔力炉 | 鉱石2、マナ2 | ターン開始時にマナ+1 |
| 砦 | 鉱石4 | 隣接する自勢力の石に防御効果 |
| 祭壇 | 鉱石3、影響力1 | ターン開始時に影響力+1 |
施設は建設したマスが敵に奪われた場合、敵の所有物になる。施設効果も所有者に応じて切り替わる。施設は1マスにつき1つまで建設可能とする。
[Heading2] 3.5 施設の防御効果
[ListBullet] 砦に隣接している自勢力の石は防御状態になる。
[ListBullet] 防御状態の石は通常のオセロの反転対象にならない。
[ListBullet] 砦1つにつき最大4方向の隣接マスに効果を与える。
[ListBullet] 砦自身が敵に奪われた場合、防御効果は解除される。
[ListBullet] 特殊能力「破城」によって防御状態を解除できる。
[ListBullet] 砦の効果は建設者の石だけに適用する。
防御石は通常のオセロルールを変更するため、通常オセロモードとストラテジーモードを明確に分離する。防御対象の選定順や複数砦の重複範囲は実装前に確定すること。
[Heading1] 4. 特殊能力システム
[Heading2] 4.1 基本仕様
[ListBullet] 特殊能力は資源を消費して発動する。
[ListBullet] 能力はプレイヤーごとに管理する。
[ListBullet] 使用可能な能力は勢力ごとに設定できるようにする。
[ListBullet] 能力の使用は自分のターンのみ可能とする。
[ListBullet] 基本仕様では1ターンに1回まで特殊能力を使用できる。
[Heading2] 4.2 初期実装する特殊能力
| 能力 | コスト | 効果・制限 |
| 魔力強化 | マナ3 | 指定した自勢力の石を強化。相手の次のターン終了まで通常の反転対象にならない。 |
| 強制反転 | マナ5 | 指定した敵石を1つ反転。防御状態の石には使用不可。 |
| 資源採掘 | なし | 鉱石+2。ゲーム中3回まで。 |
| 破城 | 影響力3 | 指定した敵施設の効果を2ターン無効化。 |
| 戦術的配置 | 影響力5 | 特殊配置可能マスに追加の石を配置。通常の配置条件を満たさない場所にも配置可能。ゲーム中1回。 |
[Heading2] 4.3 能力使用時の処理
[ListNumber] 能力選択画面を開く。
[ListNumber] 使用可能な能力を表示する。
[ListNumber] 必要資源があるか確認する。
[ListNumber] 対象マスが必要な場合は対象を選択する。
[ListNumber] 発動条件を検証する。
[ListNumber] 資源を消費する。
[ListNumber] 能力の効果を反映する。
[ListNumber] 盤面とUIを更新する。
条件を満たさない場合は能力を発動せず、資源も消費しない。
[Heading1] 5. ゲームモード
[Heading2] 5.1 通常オセロモード
[ListBullet] 資源なし

[ListBullet] 8×8盤面

[Heading2] 5.2 ストラテジーモード
[ListBullet] 資源システムあり
[ListBullet] 施設建設あり
[ListBullet] 特殊能力あり
[ListBullet] 特殊マスあり
[ListBullet] 地形効果あり
[ListBullet] オセロの基本ルールをベースに対戦
[Heading2] 5.3 AI対戦モード
プレイヤー対AIで対戦する。難易度は3段階とする。
| 難易度 | AIの特徴 |
| EASY | 合法手からランダムに選択する。 |
| NORMAL | 角、辺、資源マスの確保を優先する。 |
| HARD | 複数ターン先を探索し、資源や特殊能力も考慮する。 |
HARDでは可能な範囲でMinimax法とAlpha-Beta枝刈りを使用する。AIの思考時間には上限を設ける。
[Heading1] 6. 盤面の特殊マス・地形システム
[Heading2] 6.1 特殊マス
| 種類 | 数 | 効果 |
| マナ鉱脈 | 4 | マナ獲得 |
| 鉱石鉱脈 | 4 | 鉱石獲得 |
| 祭壇 | 2 | マナ・影響力獲得 |
| 中立拠点 | 4 | 影響力獲得 |
盤面生成時に特殊マスを配置する。盤面上で種類ごとに視覚的に区別できるようにする。通常オセロモードでは特殊マスを表示しない。
[Heading2] 6.2 地形システム
| 地形 | 効果 |
| 平地 | 特殊効果なし |
| 森林 | 防御系能力の効果が上昇 |
| 遺跡 | 施設建設コストが減少 |
| 魔力地帯 | マナ獲得量が増加 |
初期開発では平地と特殊マスを優先する。地形による複雑な効果は基本システム完成後に追加する。

[Heading2] 12.2 合法手判定
[ListNumber] 座標が盤面内か確認する。
[ListNumber] マスが空白か確認する。
[ListNumber] 8方向を順番に調べる。
[ListNumber] 隣接するマスが敵石であるか確認する。
[ListNumber] 敵石が続く限り探索する。
[ListNumber] 自分の石に到達した場合、その方向を合法方向とする。
[ListNumber] 1方向でも合法方向が存在すれば配置可能とする。
[Heading2] 12.3 反転処理
反転処理は合法手判定と同じ探索結果を使用する。合法手判定時に取得した反転対象を実際に変更する。合法手判定と反転処理で異なる探索結果を使用しないこと。
[Heading2] 12.4 重要な実装ルール
[ListBullet] 盤面外に出たら探索を終了する。
[ListBullet] 空白マスに到達したらその方向は不成立。
[ListBullet] 自分の石に到達した場合のみ反転対象を確定する。
[ListBullet] 敵石が1個も挟まれていない方向は不成立。
[ListBullet] 配置前に盤面を変更しない。
[ListBullet] 反転対象が0個なら石を配置しない。

[Heading1] 21. 最重要事項
本作で最も重要なのは、オセロの面白さを損なわずにストラテジー要素を成立させることである。特殊能力や施設が強すぎると、オセロの基本的な駆け引きが成立しなくなる。
[ListBullet] オセロの合法手判定は正確に実装する。
[ListBullet] 通常オセロとストラテジーモードの処理を明確に分離する。
[ListBullet] 特殊能力の効果とコストを適切に調整する。
[ListBullet] 施設の防御効果によってゲームが膠着しないようにする。
[ListBullet] 資源を確保することと石の数を増やすことの両方に意味を持たせる。
[ListBullet] AIは資源や施設を考慮した行動を選択できるようにする。
[ListBullet] 仕様書にない機能を勝手に追加せず、必要な場合は事前に提案する。
最終目標：オセロのルールを理解していれば誰でも始められる一方、資源管理・施設建設・特殊能力・盤面支配によって、何度でも異なる戦略を楽しめるゲームを完成させる。

[Heading1] 仕様確定時の注意事項
本書は初期開発を開始するための仕様案であり、実装着手前に以下のルールを最終確定すること。
[ListBullet] 「石の反転」と「占領状態」の関係：占領状態を石の所有者と常に同期させるのか、独立した概念として扱うのか。
[ListBullet] 施設を建設したマスの石が反転した場合、施設も同時に所有者変更するのか。
[ListBullet] 砦の「最大4方向の隣接マス」の具体的な選び方と、複数砦の防御範囲が重複した場合の扱い。
[ListBullet] 防御状態の石を挟むオセロ手の合法性：防御石を挟み列の途中に含められるか、挟めないか。
[ListBullet] 特殊能力「戦術的配置」で配置した石が反転判定を行うか、配置後に通常の反転処理を行うか。
